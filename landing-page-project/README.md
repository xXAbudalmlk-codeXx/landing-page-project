## About This Project

TJRBH Coffee is a fictional coffee shop landing page created as part of my beginner web development learning journey.

I used HTML, CSS, and JavaScript with substantial AI assistance. I am still a beginner and currently understand basic HTML elements such as `section` and `div`. Most of the code was provided through AI-generated examples that I copied, integrated, and tested while learning.

This project represents my early practice with web development, rather than independent mastery of HTML, CSS, or JavaScript.
